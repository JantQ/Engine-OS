# EnScript

## Comments

```
#C single line comment

C# multiline
comment
block C#
```

## Statements

```
set x 100
add x 4
sub x 4
mul x 2
div x 2
rnd x 10

label loop
goto loop
if x < 20 goto loop
gosub myroutine
return
end

rect x y w h color
text 10 10 "HELLO"
num 10 30 score

key right d

alloc buf 100
poke buf 5 x
peek buf 5 y

flip
wait 16
millis t
screen w h
```
